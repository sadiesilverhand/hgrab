# hgrab

## usage

```bash
hgrab https://hshop.erista.me/t/861 
```

```bash
hgrab https://download4.erista.me/content/861?token=...
```

(supports both page and direct file)

## developer
to install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

To install:

```bash
chmod +x ./build.sh
./build.sh
```
